# solumedplus.com

Static marketing site + PWA apps (Sente, RxSteward) for Solumed Plus.

Auto-deploys to the Hetzner VPS: any push to `main` shows up at solumedplus.com
within a few minutes (server cron pulls this repo).

- `sente/` — offline money tracker PWA
- `rxsteward/` — offline antimicrobial stewardship PWA
- `downloads/` — installer binaries live here on the server but aren't in git
